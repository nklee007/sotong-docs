소통 (Sotong) 개인정보처리방침

최종 업데이트: 2026년 5월 12일

본 개인정보처리방침은 RootCorp Co., Ltd. (이하 "운영자")가 제공하는 한국어↔베트남어 번역 앱 소통 (Sotong) (Android 패키지: com.rootcorp.sotong, 이하 "본 앱")의 개인정보 처리 방침을 설명합니다.

1. 수집하는 정보

항목수집 방법목적
Google 계정 이메일 + 표시 이름Google 로그인 시사용자 식별, 토큰 잔액 관리
번역 입력 텍스트사용자가 번역 요청 시번역 처리 (Google Gemini API에 일시적 전송)
결제 정보 (영수증 ID, 주문 ID)인앱 구매 시결제 검증, 토큰 충전, 중복 결제 방지
기기 무결성 토큰앱 실행 시 자동 (Google Play Integrity API)위조된 앱의 백엔드 호출 차단 (보안)
토큰 잔액 / 사용 내역번역/충전 시 서버 측 기록잔액 관리, 거래 내역 표시

2. 정보의 사용 목적

  • 본 앱의 핵심 기능(번역, 토큰 잔액 관리, 결제) 제공
  • 위조 앱·자동화 봇으로부터의 서비스 보호
  • 오류·악용 패턴 분석 및 서비스 개선
  • 법적 요구사항 준수

3. 정보의 제3자 제공 및 처리위탁

본 앱은 다음의 제3자 서비스를 활용하며, 해당 서비스 처리 시 일부 정보가 전달됩니다.

서비스전달 정보목적
Google Firebase AuthenticationGoogle 계정 인증 토큰로그인 처리
Google Firebase Firestore토큰 잔액, 거래 내역잔액 영구 저장
Google Firebase Cloud Functions번역 요청, 영수증 검증 요청서버 측 비즈니스 로직 실행
Google Gemini API번역 입력 텍스트 (서버 경유, 일시적)AI 번역 생성
Google Play Billing결제 영수증인앱 구매 처리
Google Firebase App Check (Play Integrity)기기 무결성 토큰위조 앱 차단

모든 제3자 서비스는 Google LLC에서 제공하며, Google의 개인정보처리방침이 함께 적용됩니다: https://policies.google.com/privacy

4. 정보의 보유 및 삭제

  • 번역 입력 텍스트: 본 앱은 번역 입력 텍스트를 자체적으로 저장하지 않습니다. Gemini API로 전송된 후 즉시 폐기됩니다.
  • 계정/잔액 정보: 사용자가 계정 삭제를 요청할 때까지 보유합니다.
  • 결제 영수증: 중복 결제 방지를 위해 영구 보관합니다.
  • 계정 삭제 요청: 아래 연락처로 요청 시 영업일 기준 7일 이내 삭제 처리합니다.

5. 이용자의 권리

  • 본인의 개인정보 열람 요청
  • 본인의 개인정보 정정 또는 삭제 요청
  • 본 앱 사용 중단 (앱 삭제 시 클라이언트 캐시는 즉시 제거되며, 서버 측 정보 삭제는 별도 요청 필요)

6. 미성년자의 개인정보

본 앱은 만 13세 미만의 어린이로부터 의도적으로 개인정보를 수집하지 않습니다. 만 13세 미만 어린이의 정보가 수집된 사실을 인지할 경우 즉시 삭제합니다.

7. 보안 조치

  • 모든 통신은 HTTPS로 암호화됩니다.
  • API 키는 클라이언트에 저장되지 않으며, Firebase Secret Manager로 서버 측에만 보관됩니다.
  • App Check (Play Integrity)로 위조 앱의 백엔드 접근을 차단합니다.

8. 정책의 변경

본 방침은 법령·서비스 변경에 따라 수정될 수 있으며, 변경 시 본 페이지에 게시합니다.
